개인정보처리방침

시행일: 2026년 7월 7일 | 최종 수정: 2026년 7월 4일

Anonymous Shorts(이하 "서비스")는 「개인정보 보호법」 및 관련 법령에 따라 이용자의 개인정보를 보호하고, 이와 관련한 고충을 신속하게 처리할 수 있도록 다음과 같이 개인정보처리방침을 수립·공개합니다.

1. 수집하는 개인정보 항목

항목수집 목적보유 기간
기기 고유 식별자(UUID)익명 사용자 식별, 투표/크레딧 관리, 어뷰징 방지서비스 이용 기간

※ 서비스는 이름, 이메일, 전화번호 등 직접적인 개인 식별 정보를 수집하지 않습니다.

2. 개인정보의 처리 목적

  • 서비스 기본 기능 제공 (콘텐츠 작성, 투표, 피드 노출)
  • 부정 이용 방지 및 서비스 안전성 확보 (중복 투표 방지, 신고 처리, 블랙리스트)
  • 법적 의무 이행 (정보통신망법에 따른 통신사실 확인자료 보관)
  • 콘텐츠 모더레이션 (자동 필터링 시스템을 통한 유해 콘텐츠 차단)

3. 개인정보의 보유 및 이용 기간

  • 기기 식별자(UUID): 서비스 앱 삭제 또는 데이터 삭제 요청 시까지
  • IP 주소 및 콘텐츠 아카이브: 생성일로부터 90일 후 자동 삭제
  • 피드 콘텐츠: 생성 후 24시간 경과 시 피드에서 자동 소멸

4. 개인정보의 제3자 제공

서비스는 원칙적으로 이용자의 개인정보를 외부에 제공하지 않습니다. 다만 다음의 경우에는 예외로 합니다:

  • 법령에 의거하거나, 수사기관의 적법한 절차에 따른 요청이 있는 경우

5. 개인정보의 처리 위탁

위탁 대상위탁 업무
OpenAI, Inc.콘텐츠 모더레이션 (텍스트 유해성 판별)

위탁된 데이터는 익명화된 텍스트만 전달되며, 개인 식별 정보는 포함되지 않습니다.

6. 이용자의 권리 및 행사 방법

이용자는 다음의 권리를 행사할 수 있습니다:

  • 데이터 삭제 요청: 앱을 삭제하면 기기에 저장된 모든 데이터(UUID, 설정)가 삭제됩니다. 서버에 저장된 데이터의 삭제를 원하시면 아래 연락처로 요청해 주세요.
  • 개인정보 열람/정정/삭제 요청: 아래 연락처를 통해 요청하실 수 있습니다.

7. 개인정보 보호를 위한 기술적·관리적 조치

  • HMAC 서명 기반 API 인증으로 무단 접근 차단
  • UUID의 암호화 저장 (flutter_secure_storage)
  • BCrypt 해시를 통한 관리자 인증 정보 보호
  • API 요청 속도 제한 (Rate Limiting)
  • HTTPS를 통한 데이터 전송 암호화

8. 자동 수집 장치의 운용

서비스는 쿠키를 사용하지 않습니다. 분석 도구나 제3자 추적기는 사용하지 않습니다.
